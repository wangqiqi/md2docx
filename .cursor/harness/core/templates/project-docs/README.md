# project-docs — 项目持久文档骨架

号位 = **瀑布阶段**（不可变），名称按项目类型替换。规则 → `.cursor/rules/execution/project-docs.mdc`；
配置 → `.cursor/config/docs-layout.json`（`profile` · `slots` · `max_numbered`）。

## 用法

1. 选 profile（或让 `/learn` 据仓库证据建议）：`web-fullstack` · `api-service` · `frontend-app` · `library` · `cli-tool`
2. 按 profile 把骨架复制到项目 `docs/`，**按映射表改名**（例：`library` → `03_ABI契约.md`）
3. 只创建启用的号位；**必选** `01` `02` `06` `08` `10` + `ROADMAP.md` 不可缺
4. `07` / `08` 由 `/manual` · `/report` 生成，**不要手写**
