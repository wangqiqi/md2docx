# md2docx 文档

本站由 [VitePress](https://vitepress.dev/) 构建，部署于 GitHub Pages。

## 在线阅读

**https://wangqiqi.github.io/md2docx/**

在仓库 **About → Website** 也可直接进入。

## 本地预览

```bash
npm install
npm run docs:dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173/md2docx/`）。
